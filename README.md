# Booking API

REST API для бронирования столиков в ресторане. Создание брони, просмотр списка с фильтром по дате, получение по ID и отмена без удаления записи.

## Стек

- Основное: Java 21, Spring Boot 3.x
- БД: H2, Flyway
- Дополнительное: MapStruct, Lombok, Springdoc-OpenAPI, Maven Wrapper, JUnit / Mockito

## Запуск через Docker

Требуются Docker и Docker Compose. В docker-copmpose.yaml определены параметры для работы приложения. Для запуска в корневой директории выполните команду:

```sh
docker compose up --build -d
```

Для остановки выполните команду:

```sh
docker compose down
```

## Локальный запуск

Требуется JDK 21. Все команды выполняются из корня проекта. Для сборки приложения в Windows PowerShell выполните команду:

```powershell
.\mvnw.cmd clean package
```

В Linux / macOS:

```sh
sh ./mvnw clean package
```

Для запуска приложения после сборки выполните команду:

```sh
java -jar target/booking.jar --spring.datasource.url=jdbc:h2:file:./target/data/db --spring.datasource.username=sa --spring.h2.console.enabled=true --booking.properties.days=90 --booking.properties.guests=12 --booking.properties.bookings=10 --booking.properties.open=12:00 --booking.properties.closed=22:00
```

## Принятые решения

Контроллер отвечает за первичную работу с запросами и входными данными в них, сервис — за бизнес-правила, репозиторий — за доступ к данным. Bean Validation проверяет данные на соответствие формату, а сервис — на соответствие бизнес-правилам. H2 сохраняет данные между запусками без внешней СУБД. Clock позволяет провести тесты с использованием фиксированных часов и при необходимости настроить другой часовой пояс. Некоторые параметры определены в ресурсах, потому что они жестко связаны с используемыми зависимостями.

## Дополнительно реализовано

- Flyway-миграции для контроля и версионирования схемы хранимых данных.
- Многоэтапная сборка приложения в Docker без лишних файлов в готовом образе.
- Docker Compose для простого запуска одной командой с настраиваемыми параметрами и томом для базы.
- Юнит-тесты отмены бронирования.
